# 1. Stack and repository layout

Date: 2026-10-29
Status: accepted

## Context

Isolator needs a web app, an API, and later background workers for scans and AI-assisted assessments. The team already runs NestJS + Drizzle + Postgres and React + Vite in other projects (e.g. navio).

## Decision

- npm workspaces monorepo: `apps/*`, `packages/*`.
- `apps/api`: NestJS, Drizzle ORM, Postgres 17 (`postgres` driver). Migrations generated by drizzle-kit and committed.
- `apps/web`: React 19, Vite, React Router, Tailwind v4. Dev server proxies `/api` to the API.
- Multi-tenancy by `organization_id` on every customer-owned table, single database.
- Control catalogs are seeded from TypeScript data files, keyed by `(framework, ref)`, so later frameworks (NIS2, TISAX, SOC 2) can sit next to Annex A 2022.

## Consequences

- One language end to end; shared types can move into `packages/` when the web app starts consuming API types.
- Auth, background jobs and scanners are not decided yet and will get their own ADRs.
